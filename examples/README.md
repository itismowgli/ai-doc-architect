## Which example for which situation

**First time using the skill?**
Read `00-prompt-library.md`, pick a prompt, run it.

**Want to see the output before committing?**
Read `05-output-showcase.md` — real file contents, not descriptions.

**Have a codebase, no docs, no time?**
`/autodoc .` — the prompt is two words. See `02-autodoc.md` for what happens.

**Have specs in Linear, Confluence, Jira, or Notion?**
See `03-prd-to-manual.md` for the reconciliation flow and gap report.

**Docs exist but might be stale?**
See `04-gap-report.md` — what a sprint's worth of drift looks like and how to fix it.

**Want to understand every question the wizard asks?**
Read `01-wizard-walkthrough.md` — the full dialogue from scan to 43 generated files.
